# COVID-19 Data Cleaning and Visualisation

## 1. Project Overview

This project analyses daily COVID-19 data stored in a JSON file and visualises the information in two different ways using Python.

The project contains two implementations:

1. **Library-based visualisation** — uses Pandas to process data and Matplotlib to generate graphical charts saved as PNG files.
2. **Standard-library-only visualisation** — uses Python's built-in modules to clean and process data and displays graphs directly in the terminal using asterisks (`*`).

Both implementations aim to make COVID-19 statistics easier to understand by showing changes in confirmed cases, deaths, recoveries and active cases over time.

## 3. Input Data

The programs read daily COVID-19 records from a JSON file.

The important fields include:

- `Date` — the date of the observation.
- `Total Confirmed Cases` — cumulative confirmed cases.
- `Total Deaths` — cumulative reported deaths.
- `Total Recovered` — cumulative recoveries.
- `Active Cases` — active cases recorded for that date.
- `Daily Confirmed Cases` — newly confirmed cases reported that day.
- `Daily deaths` — daily reported deaths. The source data may contain inconsistent spacing in this field name.

Example record:

```json
{
  "Date": "2020-03-05",
  "Total Confirmed Cases": "1 234",
  "Total Deaths": "12",
  "Total Recovered": "100",
  "Active Cases": "1 122",
  "Daily Confirmed Cases": "25",
  "Daily  deaths": "2"
}
```

Some numbers are represented as strings and use spaces or commas as thousands separators. The programs clean these values before using them in calculations and graphs.

|---|---|

| `re` | Removes commas and whitespace from numeric strings. |
| `pathlib.Path` | Handles file and directory paths. |
| `pandas` | Organises records into a DataFrame and processes columns. |
| `matplotlib.pyplot` | Creates, formats and saves charts. |

Install the external dependencies with:

```bash
python -m pip install pandas matplotlib
```

## 5. How the Library-Based Program Works

The program follows a data-processing pipeline:

1. Accept the input and output paths.
2. Load the JSON records.
3. Validate the input structure and required fields.
4. Clean numeric values and standardise dates.
5. Create the charts.
6. Export the cleaned data to CSV.
7. Print the locations of the generated files.

### 5.1 The `to_number()` Function

This function converts a value into a number that can be used in calculations.

```python
def to_number(value):
    if value is None or value == "":
        return 0

    if isinstance(value, (int, float)):
        return value

    cleaned = re.sub(r"[,\s]", "", str(value))
    return float(cleaned) if cleaned else 0
```

The function handles several cases:

- `None` and empty strings become `0`.
- Existing integers and floats are returned unchanged.
- Commas and whitespace are removed from strings.
- The cleaned string is converted to a floating-point number.

For example, `"61 927"` becomes `61927`, while `"1,234"` becomes `1234`.

The regular expression `r"[,\s]"` matches either a comma or a whitespace character.

**Limitation:** a non-empty string that is not a valid number, such as `"unknown"`, raises a `ValueError`. This function does not silently replace all invalid strings with zero.

### 5.2 The `load_data()` Function

This function loads and prepares the data for visualisation.

**Step 1: Read the JSON file**

```python
with open(input_path, "r", encoding="utf-8") as file:
    records = json.load(file)
```

The `json` module converts the JSON content into Python objects.

**Step 2: Validate the input**

The program checks that the JSON contains a non-empty list of records. It also checks for required columns, including the date, cumulative totals, active cases and daily confirmed cases.

If the input is invalid or required fields are missing, the program raises a `ValueError` with a descriptive message.

**Step 3: Create a DataFrame**

```python
df = pd.DataFrame(records)
```

A Pandas DataFrame organises the records into rows and columns. This makes it easier to clean columns and generate charts.

**Step 4: Standardise and sort dates**

```python
df["Date"] = pd.to_datetime(
    df["Date"],
    format="mixed",
    errors="coerce"
)

df = df.dropna(subset=["Date"]).sort_values("Date").copy()
```

Pandas converts recognised dates into datetime values. Invalid dates become missing values and are removed. The remaining records are sorted chronologically.

**Step 5: Convert numeric columns**

The program applies `to_number()` to the relevant numeric columns. This makes values such as `"61 927"` usable as numbers rather than strings.

**Step 6: Handle daily deaths**

The original data may contain a field named `Daily  deaths` with extra spaces. The program searches for a column whose stripped, lower-case name is `daily deaths`.

If the column exists, its values are cleaned and stored under the standard name `Daily Deaths`. If it does not exist, `Daily Deaths` is set to zero for every record.

Finally, `load_data()` returns the cleaned DataFrame.

### 5.3 The `create_charts()` Function

This function generates the visual outputs and exports the cleaned data.

It first creates the output directory if it does not already exist:

```python
output_dir.mkdir(parents=True, exist_ok=True)
```

The `parents=True` option allows missing parent directories to be created, while `exist_ok=True` prevents an error if the directory already exists.

#### Chart 1: COVID-19 Dashboard

The dashboard contains three vertically arranged graphs.

**Graph A — Cumulative totals**

Uses line graphs to compare:

- Total confirmed cases
- Total recovered
- Total deaths

These values represent cumulative totals, so the chart shows how the recorded totals change over time.

**Graph B — Daily confirmed cases**

Uses a bar chart to show the number of new confirmed cases reported on each date.

This helps identify increases and decreases in daily reported cases.

**Graph C — Active cases**

Uses a line graph to show active cases over time.

This helps analyse the changing number of cases classified as active in the dataset.

The dashboard is saved as:

```text
covid_charts/covid_dashboard.png
```

#### Chart 2: Daily Reported Deaths

A separate bar chart displays daily deaths.

Daily deaths are separated from the dashboard because their scale may differ substantially from cumulative totals. A separate chart can make daily changes easier to inspect.

The file is saved as:

```text
covid_charts/daily_deaths.png
```

#### Cleaned CSV Export

The program exports the cleaned DataFrame:

```python
df.to_csv(csv_path, index=False)
```

The resulting file is:

```text
covid_charts/covid_cleaned.csv
```

The CSV can be reused in spreadsheet applications or other data-analysis tools. The `index=False` argument prevents Pandas from adding its own row index as an extra CSV column.

After generating the files, the program prints the number of records processed, the date range and the output file paths.

# Part B: Standard-Library-Only Visualisation

## 7. Technologies Used

The second implementation uses Python's built-in modules only:

| Module | Purpose |
|---|---|
| `json` | Reads the input JSON file. |
| `os` | Handles file paths and determines the script directory. |
| `sys` | Reads positional command-line arguments and reports errors. |
| `datetime` | Parses, compares and formats dates. |

This implementation does not require Pandas or Matplotlib. It performs the cleaning and graph construction manually and prints the results in the terminal.

## 8. How the Standard-Library Program Works

The program follows this pipeline:

1. Read the input filename and selected data field from the command line.
2. Load the JSON records.
3. Standardise column names and clean numeric values.
4. Parse dates and sort records chronologically.
5. Print a star-based bar graph.
6. Print a text-based trend graph.
7. Report file or data errors to standard error.

### 8.1 The `standardize_column()` Function

```python
def standardize_column(name):
    return " ".join(str(name).lower().split())
```

This function standardises column names by:

- Converting the name to a string.
- Converting it to lower case.
- Removing leading and trailing whitespace.
- Replacing repeated internal whitespace with a single space.

For example:

```text
"Daily  deaths"       -> "daily deaths"
" TOTAL Confirmed "   -> "total confirmed"
```

This helps the program recognise fields even when their capitalisation or spacing differs.

### 8.2 The `extract_value()` Function

This function retrieves a value from a record using a requested column name.

```python
def extract_value(record, wanted_column):
    wanted = standardize_column(wanted_column)

    for column, value in record.items():
        if standardize_column(column) == wanted:
            return value

    return None
```

Instead of requiring an exact match, it standardises each column name before comparing it with the requested name.

If a matching field is found, its value is returned. If no matching field exists, the function returns `None`.

This is particularly useful for handling inconsistent spacing in the source data.

### 8.3 The `clean_value()` Function

This function converts source values into integers without using regular expressions.

```python
def clean_value(value):
    if value is None or str(value).strip() == "":
        return 0

    first_clean = str(value).replace(",", "")
    cleaned = "".join(first_clean.split())

    try:
        return int(float(cleaned))
    except ValueError:
        return 0
```

It works as follows:

1. Missing or blank values become zero.
2. Commas are removed using `replace()`.
3. Whitespace is removed using `split()` and `join()`.
4. The result is converted into a number.
5. Invalid numeric strings return zero.

For example, `"61 927"` becomes `61927`, and `"1,234"` becomes `1234`.

Unlike the library-based version, this function uses `int(float(cleaned))`. Therefore, decimal values are truncated to integers rather than preserved as floating-point numbers.

### 8.4 The `standardize_date()` Function

```python
def standardize_date(value):
    for fmt in ("%Y/%m/%d", "%Y-%m-%d", "%d/%m/%Y"):
        try:
            return datetime.strptime(value, fmt)
        except (ValueError, TypeError):
            pass

    return None
```

This function tries three date formats:

- `YYYY/MM/DD`
- `YYYY-MM-DD`
- `DD/MM/YYYY`

If a date matches one of the formats, it is returned as a `datetime` object. If none matches, the function returns `None`.

Unlike Pandas' date parser, this function supports only the explicitly listed formats.

### 8.5 The `get_date()` Function

```python
def get_date(item):
    return item[0]
```

Each cleaned record is stored as a tuple containing its parsed date and record data.

`get_date()` extracts the date from that tuple so Python's sorting function can order the records chronologically.

### 8.6 The `load_data()` Function

This function loads and cleans the JSON file without Pandas.

**Step 1: Read the file**

```python
with open(filename, encoding="utf-8") as file:
    data = json.load(file)
```

**Step 2: Support two JSON structures**

If the top-level JSON value is a dictionary, the program attempts to retrieve a list from its `data` key. If the value is not a list after that step, the function raises a `ValueError`.

The program therefore supports either a list of records or a dictionary containing a `data` list.

**Step 3: Clean each record**

For every record, the program extracts and parses the date. Records with invalid dates are skipped.

Column names are standardised, and non-date values are passed through `clean_value()`.

**Step 4: Sort the records**

The records are sorted by their parsed dates. If no valid records remain, the function raises a `ValueError`.

The function returns a list of tuples:

```text
[
    (parsed_date, cleaned_record),
    (parsed_date, cleaned_record)
]
```

This structure allows the graphing functions to access both the date and the cleaned values without requiring a DataFrame.

### 8.7 The `star_graph()` Function

This function creates a horizontal bar graph using asterisks printed in the terminal.

```python
stars = round(value / maximum * 40) if maximum else 0
```

The calculation scales the largest value to a maximum of approximately 40 stars. Other values receive proportionally shorter bars.

For example, if the largest value is 100:

```text
VALUE
-----------------------------------------------------------------
20200305 | ******************** 50
20200306 | **************************************** 100
20200307 | ********** 25
```

The graph displays:

- The date in `YYYYMMDD` format.
- A bar made from asterisks.
- The actual numeric value.

Showing the numeric value alongside each bar preserves the exact integer value represented by the graph, while the stars provide a quick visual comparison.

If all values are zero, the program avoids division by zero and prints bars with no stars.

### 8.8 The `trend_graph()` Function

This function produces a second terminal graph designed to show the trend of a selected field.

Unlike the star graph, which uses a horizontal bar for each record, the trend graph places a star at the approximate vertical position corresponding to each value.

Its main steps are:

1. Extract dates and numeric values.
2. Reduce the number of points if there are more records than the configured chart width.
3. Determine the minimum and maximum values.
4. Create a character grid.
5. Map each value to a vertical row.
6. Print the rows with numeric labels.

The default settings are:

```python
def trend_graph(rows, field, height=10, width=60):
```

- `height=10` gives the graph ten vertical positions.
- `width=60` limits the number of displayed data points to approximately 60.

If there are too many records, the program selects evenly spaced points from the series to keep the graph readable in the terminal.

If all values are identical, the function adjusts the upper bound to avoid division by zero.

The result is a simple visual indication of whether the selected statistic rises, falls or stays relatively stable over the selected period.

Because the vertical positions are scaled between the minimum and maximum values, the graph is primarily useful for showing the shape of the trend. It is not intended to provide the same numerical precision as a conventional chart.

### 8.9 The `main()` Function

The standard-library version uses positional command-line arguments instead of `argparse`.

```python
filename = sys.argv[1] if len(sys.argv) > 1 else "covid.json"
field = sys.argv[2] if len(sys.argv) > 2 else "Daily Confirmed Cases"
```

The first argument specifies the input filename. The second specifies the field to visualise.

If neither is supplied, the program uses `covid.json` and `Daily Confirmed Cases`.

The program resolves relative input paths against the directory containing the script. This allows the default JSON file to be found even if the program is launched from another working directory.

If loading or validation fails, the program prints an error message to standard error and exits with status code `1`.
